# AndroidApp_ProblemReportApp

This is the mobile application code of the Problem Report App for Android. The application has the following functionality:

Quickly take photos, track the location of the user, save the user's added comments, and encrypt all of this data, sending it to a server (For testing purposes - the server was local).

The server-side of the application is available at https://github.com/MindaugasKazlavickas/PythonServer_ProblemReportApp
